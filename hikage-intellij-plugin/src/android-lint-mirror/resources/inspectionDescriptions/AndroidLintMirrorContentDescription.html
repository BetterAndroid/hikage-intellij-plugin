Reports non-textual Hikage components that do not provide an accessibility description.

Non-textual widgets like ImageView and ImageButton should use the contentDescription attribute to specify a textual description of the widget so that screen readers and other accessibility tools can adequately describe the user interface.

Elements that are purely decorative and do not provide content or enable a user action should use @null, or android:importantForAccessibility="no" when the minimum SDK permits it. Text fields should not set both hint and contentDescription, because the content description masks the hint.
