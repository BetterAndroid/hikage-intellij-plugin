Reports left/right attributes and gravity values that should use start/end for right-to-left layouts.

Using Gravity.LEFT and Gravity.RIGHT can lead to problems when a layout is rendered in locales where text flows from right to left. Use Gravity.START and Gravity.END instead. Similarly, in XML gravity and layout_gravity attributes, use start rather than left.

For XML attributes such as paddingLeft and layout_marginLeft, use paddingStart and layout_marginStart. If the minimum SDK version is less than 17, add both the older left/right attributes and the new start/end attributes. Older platforms ignore the unknown start/end attributes, while newer platforms need them for right-to-left layouts.

Gravity.LEFT and Gravity.START are compatible on older platforms because the start bitmask is a superset of the left bitmask. Therefore, use gravity="start" instead of gravity="left|start".
